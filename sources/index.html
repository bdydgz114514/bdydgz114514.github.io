Pipeline

采集与理解流程

归档视频经 L0–L6 流水线处理后导出为本站的 JSON 数据；站点只做展示，不做抓取。

  1. L0

    索引

    ffprobe 抽取全量元数据（时长 / 编码 / 分辨率 / 音轨），落 SQLite assets 表。

  2. L1

    听觉

    Whisper large-v3 词级时间戳转写 + 术语纠错 + 音乐/音效标签（CLAP / librosa）。

  3. L2

    视觉

    PySceneDetect 场景切分，Qwen3-VL 逐帧画面理解，RapidOCR 补充画面文字。

  4. L3

    对齐

    现有 SRT/TXT + ASR + OCR 三源按时间轴合并，ASR 为主、OCR 补画面。

  5. L4

    场景卡

    每个场景产出 {t0,t1,画面,台词,声音,画面文字,人物,情绪}，即本站的「逐场景理解结果」。

  6. L5

    视频级

    一句话摘要 + 要点 + 实体关系 + 标签 + 时间线锚点。

  7. L6

    知识库

    SQLite FTS5 全文 + 向量索引 + 实体关系图。

  8. L7

    站点

    Astro 静态站 + Pagefind 搜索；构建期只读 src/data/*.json，不访问网络。
