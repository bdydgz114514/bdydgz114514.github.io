李文亚知识库

把 1,206 个归档视频（约 170.1 小时）逐视频「看懂」之后得到的可溯源多模态知识库： 听（转写）→ 看（画面理解）→ 读（画面文字）→ 融合（场景卡与摘要）→ 入库（全文 + 语义 + 实体关系）。 本页是知识库的入口：可以下载全部数据，也可以按下面的说明直接检索。

五层流水线

L0–L2 资产索引与转写

ffprobe 建索引；Whisper large-v3 转写（VAD 只跑语音段 + 时间戳回填），得到带时间码的台词，并过滤模板幻觉。

L3–L4 画面理解

PySceneDetect 场景切分 → 关键帧 → Qwen3-VL-8B 结构化描述（场景 / 人物 / 动作 / 画面文字 / 风格 / 情绪），OCR 补画面文字。

L5 融合成卡

按场景把台词、画面、文字、人物合成「场景卡」，再由本地 Qwen3-8B 生成视频级摘要与人物 / 理论 / 梗标签。

L6–L7 知识化与检索

入库 SQLite（FTS5 全文）+ FAISS（语义）+ 实体关系图；所有结论都带 video_id + 时间码，可逐条回溯。

快速使用

# 1) 全文检索（SQLite FTS5，无需任何依赖）
sqlite3 liwenya_kb.sqlite \
  "select d.title, c.text from chunk c join doc d on d.id=c.doc_id \n   where c.rowid in (select rowid from chunk_fts where chunk_fts match '黑体生物') limit 5;"

# 2) 语义检索（FAISS + 向量）
python scripts/kb.py query --text "黑体生物 延寿"

# 3) 按视频查转写片段
python movie/tools/kb_lookup.py 电线 --limit 8
python movie/tools/kb_lookup.py --video 603

检索块与向量一一对应：embeddings.npy 的第 i 行 = chunk_ids.json 的第 i 个 chunk_id。
